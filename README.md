# The Pencil Mark Beside the Kettle

This entry is a late-night phone call remembered months on: a stranger's voice staying on the line, a measurement spoken aloud in the dark, and the same measurement written in pencil on the kitchen wall — read every morning since while the water boils, a small record of the night something finally held.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```

The program writes the entry text to `entry.txt` inside the directory given by `MAKEFUN_OUTPUT_DIR` (or `/output` when the variable is not set), then reads the file back and verifies its contents match the entry text byte-for-byte. It uses only the Python standard library, needs no network access, and exits with a non-zero code if any check fails.
